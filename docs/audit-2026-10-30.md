**证据**

**影响面**　门禁非确定性 = 团队会开始"习惯性忽略红"。这正是"测试全绿但线上失效"的镜像形态（常红 ⇒ 真红也被忽略）。本轮体检能发现 P0-1 之类静默缺陷，靠的不是门禁而是人工筛查，说明门禁信号已不可依赖。

**建议（方案，本轮不实现）**

1. **把"环境受限"与"代码缺陷"三分类，而不是二分类**（现状只有 硬失败 / INFO 静默两档）：
   - `FAIL`：根异常命中业务异常白名单之外的一切 —— `TypeError / KeyError / AttributeError / NameError / ImportError / SyntaxError` 等，**永远硬失败**，不因网络放水。
   - `SKIP`：根异常命中**受限网络签名**（`HTTP Error 451|403|429|5\d\d`、`urlopen error`、`[SSL:`、`ConnectionReset/Refused`、`timed out`、`getaddrinfo failed`、`Max retries exceeded`），**显式打印 SKIP 与原因**，并且**计数器单独累加 `skipped`**。
   - `INFO`：无参挂起（`backtest.py` / `news_watch.py`）—— 保持现状，因为那确实是"流水线从不裸调"的设计外行为。

2. **SKIP 必须进入汇总且可见**：`test-scripts-smoke.py` 结尾打印 `test-scripts-smoke: N/N 通过, M 项 SKIP（受限网络：new_listing.py, screener.py → HTTP 451）`；`run-all-tests.ps1` 的 PASS 行也要带上 `skipped`。**门禁不允许出现"静默跳过"**——这正是本轮 P0-2 的反面教训。

3. **SKIP 率设阈值做成红灯**：若 `skipped / total > 某阈值`（例如 20%），或**同一个脚本连续 3 次运行都 SKIP**，则整步失败并要求人工确认——防止"SKIP 变成新的永远绿"。

4. **另加一条与网络无关的真修复（P2，独立排期）**：给 `new_listing.py` / `screener.py` 增加"无参即打印用法并退出 2"或引入显式 `--scan` 子命令，让"模型漏参"不再触发联网。注意这会改变现有行为，需同步 `test-scripts-smoke.py:131-137` 的注释与 INFO 名单。

**影响面**

- **正面**：门禁从"随机红绿"变成"确定性判定"；451/403 时段不再制造假红，而 `TypeError`/`KeyError` 类真缺陷仍 100% 硬失败（本轮正则验证已证明这两类都 `NO-MATCH`，不会被放水）。`FAIL` 重新变成可信信号。
- **风险 1**：SKIP 一旦无阈值约束，会退化成"新的永远绿"。必须配第 3 条阈值。
- **风险 2**：把 451/403 加入签名，等于承认"部分地区受限"是常态；对**取数类**脚本这可能掩盖"某个源真的挂了"。缓解：SKIP 行必须打印具体脚本名 + HTTP 码，且由第 3 条的连续 SKIP 检测兜住。
- **风险 3**：不覆盖 `datasources.py` 等其余联网脚本——它们当前无参运行时要么不联网、要么已被 `[SSL:`/`urllib.error` 分支接住；改签名后它们的归类不变（本条不改其行为）。
- **不影响**：`test-cex-live-safety.py`（49 项）、`test-derivs-crosssource.py`、`test-unlock-fetch.py` 等**自带网络容错断言**的用例不依赖本签名表，改动不外溢。

**本轮是否必修**：**是（P1），但按 lead 指示本轮"先定性、不实现"**。判定与方案已定稿；实施应在下一轮门禁改造中连同 P2-6（门禁超时/编码）一起做，否则每次交付都要对"红的是不是环境"做一次人工裁决。

**日志可读性（实测）**：`Start-Process -RedirectStandardOutput` 产生的日志是**混编码**——外层 `Write-Host` 中文为 GBK，内层子进程捕获的 UTF-8 文本按 GBK 写出，形成双重 mojibake。我必须写一段按行自适应解码才能读到失败原因：

```text

```

**建议**
1. `Run-Step` 加 `-TimeoutSec`，用 `Start-Process + WaitForExit(ms)` 实现每步硬超时；超时即 kill 并打印该步最后 N 行。
