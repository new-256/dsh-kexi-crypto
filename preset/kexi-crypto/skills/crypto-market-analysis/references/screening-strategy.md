# 批量筛选策略定稿（2026-09-27 与用户共同确认）

> 本文档是"挑选近期技术上可能大涨的币种"类任务（Workflow D）的唯一策略口径。
> 任何参数调整需用户确认后同步修改本文档与 screener.py 默认值。

## 1. 标的池

- 核心池：Binance USDT 交易对按 24h 成交额排序的 **Top 100**
- 扩展池（新势币）：排名 101–300 中，**近 7 日日均成交额 ≥ 过去 30 日均值 2 倍** 的币种
- 剔除：稳定币（USDC/FDUSD/TUSD/USDP/DAI/USDE 等）、包装币（WBTC/WBETH/stETH 等）、杠杆代币（*UP/*DOWN/*BULL/*BEAR）

## 2. 信号定义（多信号打分制）

### 硬条件（4 条，命中 ≥3 方可入选）
| # | 名称 | 判定 |
|---|------|------|
| H1 | 趋势基础 | 收盘价 > MA20 且 MA20 拐头向上（MA20 > 5 根前 MA20）；或 MA5>MA10>MA20 多头排列初期 |
| H2 | 动量确认 | MACD 金叉（DIF 上穿 DEA）发生在最近 5 根内；或 DIF>0、DEA>0 且柱体连续放大 |
| H3 | 量能配合 | 5 日均量 ≥ 1.5 × 20 日均量 |
| H4 | RSI 强势区 | RSI14 ∈ [50, 70] |

### 加分项（排序用）
- 放量突破近 20 日高点且突破后 2 根内未回踩（收盘确认）：+2
- RSI 底背离：+2
- 完全多头排列（MA5>MA10>MA20>MA60）：+1
- 4h 级别共振（趋势或动量至少其一确认）：+1（仅复核阶段）

### 一票否决
- 近 30 日已涨 > 80%（不追高接盘）
- RSI14 > 80（过热）
- 近 3 日出现插针长上影（振幅 >15% 且上影线 >40% 振幅）

## 3. 时间窗口

- 扫描周期：日线（120 根）；4h 线仅用于入选前 15 名的共振复核
- 预期窗口：未来 7–14 日（与单币种短期预判口径对齐）

## 4. 收敛漏斗

1. 初筛：硬条件 ≥3 且无一票否决
2. 打分排序：总分 = 硬条件命中数 ×2 + 加分项，取前 15（同分按 24h 成交额优先）
3. 4h 共振复核：最终取 10
4. **宁缺毋滥**：不足 10 个如实输出，绝不放宽标准硬凑

## 5. 风控（三道防线）

1. **收盘确认**：所有突破以收盘价为准，盘中上影刺破不算
2. **大盘环境闸门**：BTC 位于 MA20 下方且 MACD 零下 → 市场环境"不利"，名单照常输出但整体置信度降一级并显著标注
3. **每币必附**：命中信号清单、失效位（跌破则逻辑不成立，默认 MA20 与近 10 日低点中的较低者）、风险等级

## 6. 复现方式

```bash
python scripts/screener.py --out scan_result.json --md scan_report.md
python scripts/enrich_picks.py --input scan_result.json --out scan_enriched.json --md final_report.md
```
参数：`--top 100 --surge-rank-max 300 --surge-mult 2.0 --min-hits 3 --vol-mult 1.5 --shortlist 15 --final 10`

## 7. 策略 v2 增强（2026-09-27 第二轮与用户确认）

### 7.1 恐惧贪婪指数闸门（基于 999 日回测，非拍脑袋）
回测区间 2024-01-02 ~ 2026-09-27，F&G 分区 vs BTC 后续收益：

| 区间 | 30 日中位收益 | 30 日胜率 | 闸门规则 |
|------|--------------|----------|---------|
| 极度恐惧 ≤20 | +4.15% | 71% | 标注"逆向机会窗口"，不降级，警惕下跌惯性假突破 |
| 20–80 | +0.4%~+2.8% | 52-57% | 中性，不干预 |
| 极度贪婪 ≥80 | -1.04% | 49% | **整体置信度降一级** |

关键认知：F&G 与走势**并不同步**——它是反向指标，极度恐惧优于极度贪婪，不能简单"贪婪时看涨"。

### 7.2 止盈止损三档价位
- 止损（SL）= 失效位（MA20 与近 10 日低点较低者）
- TP1 = 近 20 日高点（若价格已破则取 现价 + 1.5×ATR14）
- TP2 = max（近 60 日高点， 现价 + 2.5×ATR14）

### 7.3 突破币多渠道验证
- 催化剂检索：对入选的突破币**先用 `kexi_news` 探测一次**新闻通道（单次、带超时、结果按工作目录共享）；通道可用再用 WebSearch 查近 7 日新闻（主网升级/上所/合作/代币经济学变更），区分"有催化剂"与"纯资金炒作"；`news_available=false`（401/被拦/超时）时**显式标记「新闻面缺失」并跳过**，禁止反复尝试联网检索（省等待与 token）
- 合约过热检查：Binance 合约资金费率 >0.1% 标记"多头拥挤"
- 赛道/链/发币方：最终名单按赛道（AI/DePIN/Meme/L1/L2/RWA 等）、所在链、发币机构归类，避免名单集中于单一赛道

### 7.4 流动性深度 + 流通占比
- 盘口深度：Binance /depth，±2% 双边深度 <30 万 USDT → 标记"插针风险高"
- 流通占比：CoinGecko 市值/FDV <30% → 标记"解锁抛压风险"（数据缺失时优雅跳过）

### 7.5 已知边界（明确不做）
- 社媒风向（X/Reddit）：无可靠免费源，噪声大，不做
- 质押/解锁时间表：数据覆盖不全，仅作人工参考不入打分
- 机构资金：山寨币无可靠数据源，不做（避免伪精确）

### 7.6 v2.1 待确认改进项（2026-09-27 首次实战暴露，待用户确认后并入规则）
1. **一票否决增加"未来 14 日内有 ≥5% 供应量的大额解锁"**——实战案例：2Z 入选但 5 天后有 17.8% 供应解锁（$124M），解锁前追高统计上吃亏
2. **一票否决增加"近 12 个月内发生重大安全事件且恢复未完成"**——实战案例：RESOLV（2026-03 $80M 黑客事件恢复中）技术信号 4/4 全中入选，但属基本面黑洞，风控层标记为"建议回避"
3. **盘口深度从"仅标记"改为"扣分项"**——首次扫描 9/10 入选币 ±2% 双边深度 <30 万 U，阈值对小市值币约束力不足
4. 风控层应输出 A/B/C/D 质量分层（催化剂真实性 × 基本面风险），优先级高于纯总分排序

## 8. 赛道补涨币分析（v2.2，2026-09-27 用户确认）

### 逻辑
龙头先涨、资金随后外溢到同赛道滞涨币。主名单抓"已启动"，补涨名单抓"将启动"。

### 赛道强度评分
对内置赛道映射表（约 15 个赛道，未覆盖币归"其他"不参与）中成员 ≥3 的赛道：
`强度分 = 成员7日涨幅中位数 + 站上MA20成员占比×10 + 平均量比`，取 Top 3 强势赛道。

### 补涨候选条件（强势赛道内，且不在主名单）
- **滞涨**：7 日涨幅 ∈ (-10%, max（赛道中位数， 12%)]
- **结构成型 ≥2 条**：贴近 MA20（±5% 内）；量比 ≥1.2；RSI14 ∈ [45, 62]；MACD 柱体回升
- 通过全部一票否决项
- 每赛道至多 3 个，总计至多 8 个，按结构条数+量比排序

### 输出与使用
- 与主名单并列输出"补涨观察名单"：附触发位（20 日高点，放量突破才确认补涨启动）与失效位
- **定位是观察名单而非立即入场信号**；由 screener.py 在扫描末段基于全量结果自动生成，零额外 API 成本

## 9. 打新（新币上市）评估与规则化第二波（v2.3，2026-09-27 用户确认）

### 新币发现
拉成交额前 300 的 USDT 对的日线，**K 线根数 ≤30 即上市不足 30 天**（公开 API 无上市日期字段，此为零成本近似）。

### 鲸鱼行为分（0-15；L3 不可用时 0-10）
| 层 | 数据 | 来源 | 计分 |
|----|------|------|------|
| L1 | 顶级交易者持仓多空比（1d） | Binance 合约 API | >1.2 +3 / ≥1.0 +2 / ≥0.8 +1 |
| L1 | 顶级交易者账户多空比（1d） | Binance 合约 API | >1.2 +2 / ≥1.0 +1 |
| L2 | 大单净流入（近 1000 笔中 >$100k 的买-卖） | Binance aggTrades | >$50k +3 / >0 +2 / >-$50k +1 |
| L3 | 持币集中度 | 浏览器 API（需 ETHERSCAN_API_KEY，无 key 则 N/A） | top10<30% +5 / 30-50% +3 / 50-70% +1 |

明确不做：Arkham/Nansen/WhaleAlert 付费标签化鲸鱼追踪。

### 规则化第二波（换手铁律）
- ❌ **上市首日 24h 内绝不开仓**（价格发现期，散户给 VC/做市商接盘）
- ✅ 24–72h 入场条件（全部满足）：上市 ≥2 天；未破首日低点（3% 容差）；缩量（近 3 日均量 < 首日 50%）；企稳（近 3 日振幅 <15%）；鲸鱼分 ≥9/15（或 ≥6/10）
- 🛑 仓位 ≤10%；时间止损 72h；价格止损 -8%
- 理由：高 FDV 低流通新币首日冲高后中位回撤深，"申购即卖"红利递减；可规则化的机会在情绪释放后的修复段

### 复现
```bash
python scripts/new_listing.py --out new_listings.json --md new_listings_report.md
# 有 Etherscan key 时启用 L3：ETHERSCAN_API_KEY=xxx python scripts/new_listing.py
```

## 10. 上币分析、多交易所数据与盘前交易（v2.4，2026-09-27 用户确认）

### 10.1 多交易所数据源（scripts/exchanges.py）
统一适配层，6 家 CEX + Dexscreener（DEX 全链）：

| 交易所 | 状态 | 说明 |
|--------|------|------|
| Binance | ✅ 主源 | 现有流程不变 |
| Gate.io | ✅ | |
| MEXC | ✅ | |
| Bitget | ✅ | |
| Coinbase | ✅ | 仅现货，计价 USD |
| OKX（欧意） | ⚠️ | 当前网络代理拦截（502 tunnel）；代码已适配，网络可达时自动启用 |
| Dexscreener | ✅ DEX | 按币名检索交易对，过滤已知链 + 流动性 ≥$10k + 24h 成交 ≥$1k |

- 所有适配器失败即抛异常，调用方 try/except 优雅降级，**单所故障不影响整体**
- 用途：跨所共振验证（币在 ≥2 家所同时放量突破，信号可信度上调）；单所独有行情的"上所效应"排查

### 10.2 上币分析（scripts/listing_effect.py，交易所风评）
对每个评估币种，统计其在各交易所的**首根日 K（≈上币日期）**及上币后走势：
- 每所输出：上币日期、D1/D7/D30 涨跌幅、`window_limited`（样本不足标注，数据不作结论依据）
- 同步输出 DEX 首发池（所在链、流动性、24h 成交）
- **交易所风评模式**（`--reputation`）：对样本币种聚合，计算每所上币后 D1/D7/D30 收益中位数 + 30 日回本率 → 得到"该所上新币的历史胜率画像"
- 用法（Workflow E）：币种首发于历史破发率高的所 → 风险等级上调；一线所（币安/Coinbase）尚未上而二线所已上且走势稳 → 标注"潜在上所预期"催化剂

### 10.3 盘前交易（whales.market 等 pre-market，Agent 侧获取）
- pre-TGE 盘前价（whales.market、Bitget/Bybit pre-market 等）无免费公开 API，**由 Agent 侧 WebFetch/WebSearch 获取，不脚本化**
- 解读规则：
  - 盘前价 vs 开盘首日价偏离 >50% → 标注"盘前情绪过热"，第二波条件收紧（鲸鱼分要求 +2）
  - 盘前成交活跃 + 开盘后缩量企稳 → 与规则化第二波条件叠加，不改变其他条件
  - 盘前数据获取失败 → 如实标注"盘前数据缺失"，不影响脚本侧评估结论

### 10.4 复现
```bash
python scripts/listing_effect.py --symbol JTO --out le.json --md le.md      # 单币跨所上币分析
python scripts/listing_effect.py --reputation --sample 30 --out rep.json    # 交易所风评画像
```

## 11. 策略 v3：位置/拥挤度/多周期（2026-09-29 与用户确认，v1.5.0）

### 11.1 问题起点（用户原话）
> "之前选币基本选的很多都是技术指标都很好，但是已经放量多天已经在高位的币种"
> "如果选币都选在高位风险有多高？比如之前有推荐 pyth，一个大回调之前的盈利位现在全变成了大阻力位"

**根因**：v2 的加分项（放量突破 +2）与硬条件 H3（量能配合）**同向叠加**，
系统性地把"已经涨完、正在派发"的币推到名单前列——技术指标确实好，
但那正是主力出货时的形态。**必须增加反向维度**。

### 11.2 回测证据（backtest.py，两轮独立样本）
| 维度 | 第一轮(Top50/step10) | 第二轮(Top100/step15) | 判定 |
|---|---|---|---|
| 已放量多日 | 30日胜率 **32.9%** vs 未放量 43.4% | 30日胜率 **32.1%** vs 39.0% | ✅ 两轮一致偏负 → **重罚 -3** |
| 多周期共振向上 | 中位 -0.04% / 胜率 48.4% | 中位 -1.22% / 胜率 41.9% | ✅ 两轮一致优于共振向下 → **保留加分** |
| 90日区间位置 | 均值受 +904%/+371% 离群币主导 | **均值差符号翻转** | ⚠️ 区分度不稳定 → 只作 **-1 风险提示**，不硬淘汰 |

> ⚠️ **方法论教训**：第一轮看均值得出"位置高反而收益高"的错误结论（被极端离群币带偏）。
> 换样本后均值差**符号直接翻转**。改为**中位数+胜率**后才看清真实关系。
> 今后任何维度有效性判断，必须报中位数与胜率。

### 11.3 调整后的打分权重（`position.py::PENALTY_WEIGHTS`）
| 项 | v1.5.0 权重 | 说明 |
|---|---|---|
| 拥挤（放量多日） | **-3** | 最重项，两轮回测一致 |
| 拉伸（MA20 偏离 >25%） | -2 | 短期过热 |
| 高位区（pos90 ≥80%） | -1 | 降级为提示 |
| 近高点（距高点 <3%） | -1 | 降级为提示 |
| 中高位区（60–80%） | -1 | |
| 180日新高 | -1 | |

**低位/中位（pos90 <60%）不扣分**，并在报告中**显式说明**"属低位/中位，不计位置扣分"——
避免用户误以为"没提到就是没看"。

### 11.4 新增输出
1. **位置画像**：90日区间位置%、距高点%、放量持续天数、MA20 偏离、窄幅横盘判定
2. **低位横盘/震荡调整候选**：60日振幅 ≤18%（`--accum-max` 控制条数）且区间位置中低——
   专门回应"低位横盘的、震荡调整的有没有考虑"
3. **大周期研判**：日线重采样出周线/月线（周一起算 UTC+8，剔除未走完周期），
   输出共振方向与得分；**逆大周期反弹扣分**
4. **多面数据源**：消息面/DEX热币/稳定币净流入/资金费率/恐贪指数/CMC热搜

### 11.5 新增铁律
- 给"买入/逢低布局"评级前，**必须同时交代** 90日位置 + 是否放量多日 + 周月线方向
- **逆大周期（月线空头）的反弹只能定为"反弹"，不得给"反转/买入"评级**
- 已在高位且放量多日者，只能给"减仓/不追"，**不得进推荐前列**
